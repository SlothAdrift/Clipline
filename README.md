# Clipline

Windows 本地图片晾衣绳。运行后驻留系统托盘；开启功能时，新的剪贴板图片自动挂到屏幕顶部，最多保留 10 张。支持 `Win+Shift+S` 截图、从其他程序复制的图片，以及在资源管理器或桌面复制的常见图片文件。

## 运行

需要 Windows 10/11 和 Python 3.10 以上：

```powershell
python -m pip install -r requirements.txt
python clothesline.py
```

Windows 免安装版、安装包及 PDF 使用手册位于 `发布版-Windows/交付/`，分别名为 `Clipline.exe`、`Clipline-安装包.exe` 和 `Clipline-产品介绍与使用手册.pdf`。安装包与 EXE 由当前源码构建，无需另装 Python。

每次运行都会显示晾衣绳窗口；首次运行时“开启 Clipline 功能”默认关闭。点击按钮开启后，复制的新图片就会自动挂上去。点击托盘图标显示或收起晾衣绳；右键托盘图标也能切换开关。也可以按 `Win + Alt + L` 或 `Ctrl + Alt + Shift + L` 从任何程序展开晾衣绳；已展开时按下会刷新闲置计时。若某组快捷键被其他程序占用，托盘会提示，另一组仍可使用。关闭时已有图片仍保留，再开启后可以继续使用。

晾衣绳显示在屏幕顶部下方约 70 像素处。光标在屏幕中部宽度约 30%～70%、距顶部 25～55 像素处静止约 0.6 秒，也可展开晾衣绳。展开时，空绳先从水平状态降至预定的弧度和位置，随后已有截图渐入；已展开时新截图仅自身渐入，原有图片随夹子移动。无图片点击、图片或猫猫悬停、翻页操作满 10 秒后，绳和截图一同上移并淡出；也可以点击绳中央的向上箭头收起；点击它左侧的 × 并确认可退出程序。显示奇数张图时中间一张保持水平。

每次最多显示 5 张；其余图片可用左右箭头每次翻动两个位置，最后不足两个时只翻动剩余位置。少于 5 张时居中悬挂。显示 5 张时，最外侧图片阴影会在左右边界前淡出，翻页动画也限制在边界内。

单击缩略图复制图片，复制成功后照片下部短暂显示“已复制”；长按约 0.65 秒用 Windows“画图”编辑图片；双击不执行打开操作。拖动图片可向其他程序或文件夹分享副本。光标移到图片上时，右上角出现 `×`，点它可取下图片。绳中央向上箭头右侧的猫猫始终可见：悬停时抬头，有图片时显示总数，无图片时提示通过截图或复制挂图；移开光标后转回正面。有图片时单击猫猫可在确认后清空全部图片，包括当前未显示的图片。原始图片不会被删除。关闭程序后 10 张图片及开关状态会保存，在下一次启动时恢复。程序使用单实例锁，避免重复启动。

图片副本和状态保存在 `%LOCALAPPDATA%\ScreenshotClothesline`。Clipline 沿用旧版数据目录，以保留已有图片和设置。取下图片或超过 10 张时，只删除该目录内由本程序保存的副本，不会删除用户原文件。程序不上传图片。

当前版本通过剪贴板接收图片；并非所有截图软件都会把结果放入剪贴板。屏幕录制、截图文件夹监视和独立标注界面尚未实现。

项目的交互灵感来自 [Tendedero](https://github.com/alejandrobujan/tendedero)，代码独立编写，未使用其名称或图标。

## 晾衣绳美术方案

效果图由 `python design_preview.py` 生成，保存在 `design_previews/`；当前猫猫按钮的运行效果见 `design_previews/runtime_cat_preview.png`。

- 绳子为银灰色，略微下垂，有多层高光与阴影，两端逐渐淡出。
- 图片相框使用轻微明暗渐变、内侧高光和连续柔和的悬浮阴影，避免底部出现生硬的灰色轮廓。
- 夹子为银白色，中央有竖直的黑色细缝。
- 图片围绕夹点随机偏转，最大绝对角度为 3°；左侧顺时针，右侧逆时针。图片数为奇数时，正中图片最终固定水平；第一张图片渐入期间会轻微晃动，再回到水平。
- 其余图片的偏转幅度使用位置相关的 Beta 分布：令 `d = 与中心的距离 / 最外侧与中心的距离`，则 `|角度| = 3° × Beta(1 + 3d, 4 - 3d)`。因此偏转幅度的期望为 `0.6° + 1.8° × d`，从内向外单调增加。该规则已接入程序；效果图使用固定随机种子，便于比较。
